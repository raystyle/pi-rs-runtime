# C2 框架参考克隆:c2 组册

> C2 框架源码参考,只克隆不安装不运行 ｜ 状态:未装(组保留;按 2026-10-14 瘦身批 不烤镜像,显式跑组可复得;后续走 MCP 服务) ｜ 组:`install-tools.sh c2`

## 版本

- 7 仓都由 pins.sh 的 `GIT_PIN` 锁定提交;`clone_pin` 在 HEAD 等于锁定提交时跳过;解析日 2026-10-10;升级:执行 `scripts/resolve-pins.sh` 更换锁定提交,再执行本组;克隆统一经 `GITHUB_MIRROR`;默认值是 `https://proxy.ohmygh.com/`;该变量置空时改为直连。规定见 [params.md](../../params.md)。

## 来源与安装

- 脚本:`scripts/install-tools.sh` 的 `install_c2`;七仓的版本、来源与路径在文末成员清单。

## 文件

- 统一放在 `/opt/c2dev-ref/<仓名>`;幂等判据是 `-d <目录>/.git`。目录存在则跳过;每次执行都删除 `/opt/c2dev-ref/ysoserial*` 残留;这些残留已经改归 maldev 组。

## 配置

- 无;只克隆,不写配置,也不固化缓存。

## 离线行为

- 支持确认参考库在位。见 [offline.md](../../offline.md);这些目录只读磁盘,不访问网络;关闭 eth0 后,`ls /opt/c2dev-ref` 退 0。

## 限制

- C2 代码不安装、不编译、不运行;自己架设 C2,就是在自己的基础设施上启动 beacon 服务。
- 供给面风险由架设者承担。见 [known-issues.md](../../known-issues.md)。
- 产物是会话的框架,归档到 `/opt/c2dev-ref`;SILENTTRINITY 是 C# 的 C2,不是语言教材;ysoserial 系是反序列化生成器,不是 C2。
- 它归 maldev 组的 `payload-ref/generators/deserialization`。
- Covenant 与 SILENTTRINITY 保留在本组;构建与运行属于部署。步骤见各仓库自己的文档。
