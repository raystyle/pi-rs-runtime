# Python 3 运行时

> 系统 python3 基座(保持干净) + /etc/pip.conf 离线面 + /opt/analytics 分析 venv + ruff ｜ 状态:已装 ｜ 组:`install-runtimes.sh python` + `install-libcache.sh python`(wheelhouse 固化)

- **版本钉**:python3、python3-pip、python3-venv、python3-dev 为 noble 源冻结即钉(apt 软钉,留痕 [known-issues](../../known-issues.md));polars、pyarrow、chdb 与 ruff pins.sh 钉版(`PYPI_PIN[polars]`=2.0.0、`PYPI_PIN[pyarrow]`=26.0.0、`PYPI_PIN[chdb]`=4.4.0、`PYPI_PIN[ruff]`=0.17.0;解析日 2026-10-10),升级跑 scripts/resolve-pins.sh
- **来源与安装**:Ubuntu noble 源(阿里云,`image-defs/ubuntu.yaml` 钉死)`apt-get install -y --no-install-recommends python3 python3-pip python3-venv python3-dev`;`scripts/install-runtimes.sh` `install_python()`;用户裁定不碰系统 python3 的 site-packages,第三方包一律进 venv 或 uv tool([ADR-0003](../../adr/ADR-0003-uv-tool-isolation-whitelist-linking.md))
- **落点**:`/usr/bin/python3`、`/usr/bin/pip3`(apt);分析 venv `/opt/analytics`(`bin/python` 等);ruff shim `/usr/local/bin/ruff`、本体 `/opt/uv-tools/ruff`;pwntools 只走 apt `python3-pwntools`(p0 批)进 dist-packages
- **配置与缓存**:`/etc/pip.conf` 双段:`[global] index-url = $PIP_INDEX`(默认阿里云 pypi simple;不加 extra-index-url 防依赖混淆)+ `[install] no-index = true / find-links = /opt/wheelhouse`——运行期 `pip install` 默认只走 wheelhouse 快失败;`pip download` 不受 `[install]` 节影响,wheelhouse 烘焙面不断;构建脚本经 `lib/common.sh` `export PIP_NO_INDEX=false` 拿回在线面(env 恒优先于配置文件)。`/opt/wheelhouse` 由 `install-libcache.sh python` 给 re-venv 装 pip 后 `pip download` 烘焙(逆向库 19 件清单及依赖:pycryptodome/cryptography/gmpy2/sympy/z3-solver/construct/pefile/pyelftools/dnfile/pypykatz/malduck/volatility3/r2pipe/httpx/beautifulsoup4/lxml/pyjwt/dpkt/xortool);分析 venv 由 `uv venv /opt/analytics` 建,`uv pip install polars pyarrow chdb`(duckdb 组随后 `-U duckdb` 进同一 venv,见 `install-runtimes.sh` `install_duckdb()`)
- **离线行为**:✅ 断网下 wheelhouse 内的包 `pip install` 免旗标直装,轮子外立即 "No matching distribution"(纯离线轮五生态实证,机制见 [offline.md](../../offline.md) §4);在线拉新件 `PIP_NO_INDEX=false pip install <包>`。验证:`ip link set eth0 down` 后 `pip install pefile`(wheelhouse 烘焙清单内)成功、`pip install <未烘焙包>` 立即报 "No matching distribution"。分析 venv 断网 import:☐ [推断:venv 为纯本地路径,import 不触网;断网冒烟未专项覆盖]
- **坑与留痕**:pwntools 若走 pip 会盖住 apt 的 dist-packages 造成双版本,裁定只走 apt(评审 F8,脚本注释留痕);ruff 用 `uv tool install` 隔离装,`UV_TOOL_BIN_DIR=/usr/local/bin`、`UV_TOOL_DIR=/opt/uv-tools` 指 /opt 使 ubuntu 可执行(评审 F5);uv 自身的离线默认与用户级配置坑见 [uv](uv.md);快失败默认化裁定见 [ADR-0004](../../adr/ADR-0004-offline-first-fail-fast.md)
