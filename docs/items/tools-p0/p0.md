# 安全分析工具集(p0 组册)

> 业界调研(Kali/REMnux/FLARE 重叠缺口)的 P0 补齐:apt 20 包 + impacket/nasm 特例 + re-venv 批 + GitHub 钉版批 ｜ 状态:已装 ｜ 组:`install-tools.sh p0`

- **版本钉**:apt 20 包 noble 随源(阿里云镜像源);impacket 与 nasm 两个特例单独成册([impacket.md](impacket.md)、[nasm.md](nasm.md));re-venv 批与 GitHub 批的逐件钉口径归各自件册(后半待补)
- **来源与安装**:`install-tools.sh` `install_p0` 段。脚本注释分三步(apt 批 / re-venv pip 批 / GitHub 钉版批);impacket 与 nasm 两个特例在 apt 批之后、re-venv 批之前执行,不计入三步——先卸 apt 冻结版 python3-impacket 再 uv 装上游版,nasm 官网源码钉版编译(各见件册)。GitHub 批经 `GITHUB_MIRROR`(默认 proxy.ohmygh.com,口径见 [params.md](../../params.md))。apt 批 20 包逐项表(noble 随源,Ubuntu 打包;入口为包常规命令名,其中 checksec/patchelf/ROPgadget/nmap/sqlmap/tshark/john/hashid 由脚本末尾核对循环实证在 PATH):

  | 包 | 入口 | 用途 |
  |---|---|---|
  | gdb-multiarch | gdb | 多架构程序调试 |
  | qemu-user-static | binfmt_misc 注册(qemu-*-static) | 用户态异架构 ELF 模拟执行 |
  | python3-pwntools | pwn 等 + `import pwn` | CTF/pwn 漏洞利用开发框架 |
  | python3-ropgadget | ROPgadget | ROP gadget 搜索 |
  | checksec | checksec | 二进制保护属性检查(NX/PIE/Canary/RELRO) |
  | patchelf | patchelf | 改写 ELF 解释器与 RPATH |
  | xxd | xxd | 十六进制转储与回写 |
  | squashfs-tools | mksquashfs/unsquashfs | SquashFS 固件镜像解包与重打包 |
  | nmap | nmap | 端口扫描与服务识别 |
  | sqlmap | sqlmap | SQL 注入自动检测与利用 |
  | tcpdump | tcpdump | 命令行抓包 |
  | tshark | tshark | Wireshark 命令行抓包与协议解析 |
  | mitmproxy | mitmproxy/mitmdump/mitmweb | HTTP/HTTPS 中间人代理 |
  | python3-scapy | `import scapy`(python3 库) | 数据包构造与嗅探库 |
  | upx-ucl | upx | 可执行文件加壳与脱壳 |
  | 7zip | 7zz | 多格式压缩解压 |
  | libimage-exiftool-perl | exiftool | 文件元数据读取 |
  | ssdeep | ssdeep | 模糊哈希与相似度比对 |
  | john | john | John the Ripper 口令破解 |
  | hashid | hashid | 哈希类型识别 |

- **落点**(批量机制):apt 包经 dpkg 落系统路径(/usr/bin 等);uv tool 件 shim 落 /usr/local/bin、本体 /opt/uv-tools/<名>(本段导出 `UV_TOOL_BIN_DIR=/usr/local/bin UV_TOOL_DIR=/opt/uv-tools`);re-venv 件本体 /opt/re-venv/bin,floss/olevba/oleid/netexec 四个入口 `ln -sf` 到 /usr/local/bin;GitHub 批钉 /opt/<名>(jadx/apktool/capa/capa-rules/yara-rules/SecLists)或直拷 /usr/local/bin(pdfid.py/pdf-parser.py)
- **配置与缓存**(批量机制):不写运行期配置、不固化缓存;构建期 `RE_VENV=/opt/re-venv`(common.sh),uv/pip 在线面经 `UV_CONFIG_FILE=/etc/uv/uv-online.toml` 与 `PIP_NO_INDEX=false` 拿回,运行期默认离线快失败([offline.md](../../offline.md) §4);netexec 缺包退 git 源、flare-floss/oletools 失败重试 --no-cache(脚本容错)。组尾「P0 核对」循环打印在位件
- **离线行为**:☐ [推断:] apt 20 包均为本地分析件,无运行期外网依赖;面向目标的动作(nmap/sqlmap 扫描、tcpdump/tshark 抓本网、mitmproxy 拦截)需到目标的网络——断外网但内网可达仍可用,eth0 全断退化为本地文件处理。发布门禁断网冒烟 78/0 通过(覆盖面含渗透/分析工具面,逐件明细未归档,[offline.md](../../offline.md))。建议验证:`ip link set eth0 down` 后 `checksec --file=/bin/ls && ssdeep /bin/ls` 退 0
- **坑与留痕**:容错演进——fresh 验证「p0 apt 批无容错(tuna 抖动)」已修为整批 `|| echo` 不退出,三批相互独立([diary 2026-10-08](../../diary/2026-10-08-build-baseline.md));apt 源实为阿里云(image-defs/ubuntu.yaml 写死),install_p0 的 log 文案「TUNA」是换源前旧口径未同步,以 yaml 与 common.sh 注释为准;特例裁定:[impacket](impacket.md) 用户裁定 uv 上游版([ADR-0006](../../adr/ADR-0006-user-rulings-log.md))、[nasm](nasm.md) 因 apt 停 2.16.01 走源码钉版;对账:脚本安装/克隆共 34 件 = apt 20(本册)+ impacket、nasm(各单独成册)+ re-venv 批 3 件 + GitHub 批 9 件(件册后半待补)
